# FreeCodeCamp JavaScript Certificate Prep

Welcome to my preparation repository for the **FreeCodeCamp JavaScript Algorithms and Data Structures Certification**. This repository contains practice exercises, notes, and implementations categorized by fundamental JavaScript topics.

## 📂 Repository Structure

The repository is organized into the following modules:

*   **`boolean-and-numbers`**: Exercises covering boolean logic, comparison operators, arithmetic operations, and working with the `Math` object.
*   **`objects`**: Code examples for creating objects, accessing properties, manipulating nested object structures, and using object methods.
*   **`variables-and-strings`**: Foundations of variable declarations (`var`, `let`, `const`), string manipulation, template literals, and basic string methods.

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/freecodecamp-javascript-certificate-prep.git
   ```
2. Navigate to a specific topic folder to review or run the code:
   ```bash
   cd freecodecamp-javascript-certificate-prep/variables-and-strings
   ```
