<summary><b>1. variables-and-strings</b></summary>
<br>

### Labs
* **Lab 1: Variable Declaration** (`variables-and-strings/labs/lab1.js`) - Declaring variables using `let` and `const`.
* **Lab 2: String Concatenation** (`variables-and-strings/labs/lab2.js`) - Combining variables and strings.
* **Lab 3: Template Literals** (`variables-and-strings/labs/lab3.js`) - Using backticks for string interpolation.
* **Lab 4: String Methods** (`variables-and-strings/labs/lab4.js`) - Utilizing `.length` and `.toUpperCase()`.
* **Lab 5: Type Coercion** (`variables-and-strings/labs/lab5.js`) - Understanding string-to-number transitions.

### Workshops
* **Workshop 1: Profile Generator** (`variables-and-strings/workshops/workshop1.js`) - Dynamically construct user bio text profiles.
* **Workshop 2: Mad Libs Game** (`variables-and-strings/workshops/workshop2.js`) - Build a classic interactive word replacement story.
* **Workshop 3: URL Builder** (`variables-and-strings/workshops/workshop3.js`) - Assemble strict query parameters safely.
* **Workshop 4: Receipt Formatter** (`variables-and-strings/workshops/workshop4.js`) - Format messy string outputs into lined columns.
* **Workshop 5: Tag Generator** (`variables-and-strings/workshops/workshop5.js`) - Wrap raw user text metadata inside sanitized HTML strings.

<summary><b>2. boolean-and-numbers</b></summary>
<br>

### Labs
* **Lab 1: Arithmetic Operators** (`boolean-and-numbers/labs/lab1.js`) - Practicing addition, subtraction, and modulus.
* **Lab 2: Truthy vs Falsy** (`boolean-and-numbers/labs/lab2.js`) - Evaluation of non-boolean types in boolean contexts.
* **Lab 3: Comparison Operators** (`boolean-and-numbers/labs/lab3.js`) - Strict versus loose equivalence testing.
* **Lab 4: Logical Operators** (`boolean-and-numbers/labs/lab4.js`) - Chaining logic with `&&`, `||`, and `!`.
* **Lab 5: The Math Object** (`boolean-and-numbers/labs/lab5.js`) - Rounding numbers with `Math.floor` and `Math.random`.

### Workshops
* **Workshop 1: Age Gate** (`boolean-and-numbers/workshops/workshop1.js`) - Validate a user's eligibility criteria based on numerical ranges.
* **Workshop 2: Tip Calculator** (`boolean-and-numbers/workshops/workshop2.js`) - Process split bills and percentage metrics programmatically.
* **Workshop 3: Dice Roller** (`boolean-and-numbers/workshops/workshop3.js`) - Create random integers inside customizable ranges.
* **Workshop 4: Even Odd Checker** (`boolean-and-numbers/workshops/workshop4.js`) - Use division remainders to route numbers accurately.
* **Workshop 5: Clearance Discount** (`boolean-and-numbers/workshops/workshop5.js`) - Compound markdown operations for sales transactions.

<summary><b>3. objects</b></summary>

### Labs
* **Lab 1: Object Creation** (`objects/labs/lab1.js`) - Constructing simple key-value pairings.
* **Lab 2: Property Access** (`objects/labs/lab2.js`) - Accessing options using dot notation and bracket notation.

### Workshops
* **Workshop 1: Inventory Tracker** (`objects/workshops/workshop1.js`) - Update and maintain item quantities inside complex stores.
* **Workshop 2: Car Dashboard** (`objects/workshops/workshop2.js`) - Manage dynamic telemetry and operational states using methods.
* **Workshop 3: Gradebook Assistant** (`objects/workshops/workshop3.js`) - Calculate average scores embedded deep within student records.
* **Workshop 4: Smart Door Lock** (`objects/workshops/workshop4.js`) - Authenticate keys securely using strict object lookups.
* **Workshop 5: Todo Manager** (`objects/workshops/workshop5.js`) - Toggle state tracking configurations on a dynamic tasks object.
